# Walkman Mp3 Player
I am working on a project with Hack Club Twisted to make an mp3 player for myself so I can listen to my music on the go without a phone, mainly because school doesn't let you use your phone anymore. The mp3 player will have a similar look to a walkman and I hope to give it a way to play cassette tapes too.


# Features I'd like to have
- Headphone Jack
- Cassette Player
- Music Selector Screen and Dial Selector
- Volume Dial
- 3d Printable Case
